# 五基因方法论白皮书 / The Five-Gene Methodology

> 本文回答一个问题：**「审美」这种通常被认为不可验证的东西，怎么变成可执行、可验收的工程动作？**
>
> 这是 **美学大脑 / aesthetic-brain** 的核心方法论。种子库是它的**素材**，决策层是它的**流程**，演示页是它的**证据**。

---

## 一、问题的起点：为什么 AI 的视觉产出总是「一个味」

让任何大模型做一张海报、一份 PPT、一个落地页，它大概率会给你：

- 居中标题 + 三张等距卡片
- 蓝紫渐变 / 通用圆角 / 柔和投影
- 一个说不出名字的「科技感」

这不是模型不够强，而是**它没有做决策**。
它做的是「把最常见的视觉统计模式采样出来」——也就是平均值。平均值没有品味，
因为**品味来自明确的选择与放弃**。

审美缺失的真正原因有两条：

1. **没有先定情绪**：不回答「读者该感受到什么」，就直接开始摆元素；
2. **没有风格纪律**：不知道「这套风格禁什么」，于是把所有好看的都放上去。

本项目做的事，就是把这两条补上。

---

## 二、核心命题：风格即基因

> **风格 = 色彩 × 光线 × 笔触 × 构图 × 情绪**

这五个维度就是风格的**基因位**。调风格是调这五个基因位，不是换个背景色。

| 基因位 | 它决定什么 | 落到代码里是什么 |
|---|---|---|
| **色彩** | 用什么颜色、几个色相、饱和度高低、强调色面积上限 | CSS 变量：`--bg` / `--text` / `--accent` / `--line` |
| **光线** | 光从哪来、有几个光源、阴影是暖还是冷、亮部占比 | `radial-gradient` 的光晕、`box-shadow`、明暗对比断言 |
| **笔触** | 边缘是硬是软、有无轮廓线、圆角量级、有无纹理 | `border-radius` / `border` / 描边策略 / 噪点与网格纹理 |
| **构图** | 主体压哪一角、留白多少、对称还是不对称、栅格或用留白分区 | 布局策略、留白占比断言、对齐规则 |
| **情绪** | 读者该感受到什么（**这个词决定前四个怎么调**） | 不直接落成 CSS，而是选择前四项时的约束条件 |

**为什么是基因而不是模板**：
模板是「照抄一个成品」，基因是「继承一套生成规则」。
同一个基因在不同场景下会长出完全不同的成品——这正是演示页里
12 张作品风格迥异、但各自都「说得清为什么这么排」的原因。

## 三、第二个命题：艺术家名即激活词

> **艺术家名字 / 风格名是 LLM 预训练美学基因的激活锚点。**

在提示词里写：

```
❌ 昏暗的、戏剧性的、高对比度的古典油画风格
```

和写：

```
✅ Caravaggio, Tenebrism, chiaroscuro, single candlelight source, deep shadow
```

后者精确得多。因为模型的预训练语料里见过**海量**关于卡拉瓦乔的作品与评论，
「卡拉瓦乔」这个词激活的是一整套已被反复讨论的视觉特征向量。
形容词是你临时构造的，艺术家名是**语料里已经锚定好的**。

本项目的职责因此被定义为两件事：

1. **帮你选对激活词**——按情绪定位到正确的种子（`references/moods/`）；
2. **把激活出的审美翻译成可执行参数**——落成 CSS 变量、版式规则、提示词骨架
   （`references/code-genes/`）。

## 四、决策流程（五步，不许跳步）

```
┌─ Step 1  情绪定位 ─────────────────────────────────────┐
│   先回答：读者该感受到什么？一个词（敬畏/治愈/紧张/怀旧/荒诞…）  │
│   ❗ 顺序不能反。情绪决定基因，不是先选风格再想表达什么        │
└───────────────────────────────────────────────────────┘
                        ↓
┌─ Step 2  选基因 ───────────────────────────────────────┐
│   按情绪查 references/moods/ 对应档案                  │
│   挑 1 主基因 + 最多 1 辅基因（敢混搭，只混一层）            │
└───────────────────────────────────────────────────────┘
                        ↓
┌─ Step 3  基因翻译（按媒介） ────────────────────────────┐
│   HTML/长图 → CSS 变量块（抄 code-genes/）             │
│   AI 生图   → Prompt Keywords + 艺术家激活词            │
│   PPT/文档  → 版式气质：底色、标题处理、信息密度、图表风格     │
│   穿搭/家居 → 材质与场景：配色逻辑、光、留白、仪式感设计       │
└───────────────────────────────────────────────────────┘
                        ↓
┌─ Step 4  一句话自检 ───────────────────────────────────┐
│   「这张作品的风格基因是什么（主 + 辅）？」                  │
│   答不上来 = 没想清楚 → 回到 Step 1                     │
└───────────────────────────────────────────────────────┘
                        ↓
┌─ Step 5  交付后记档 ───────────────────────────────────┐
│   搭配与反馈写进 references/ART-SEEDS-LOG.md（风味日志）    │
│   好用标 ✅ 复用，翻车标 ❌ 规避 → 种子库持续进化             │
└───────────────────────────────────────────────────────┘
```

## 五、五条审美铁律

这五条从东西方艺术史里被反复验证，是本项目一切风格决策的**公理层**：

### 1. 先定情绪，再选基因
顺序不能反。跳过情绪定位直接挑风格，等于让视觉形式决定内容——这是设计事故的常见起点。

### 2. 一组作品一个主基因
克林姆特的金 + 蒙德里安的网格 = 大杂烩。
单张作品允许**一个主导基因 + 最多一个辅助基因点睛**。「敢混搭，只混一层」是硬边界。

### 3. 颜色 ≤ 4；全图一种圆角、一种描边风格
颜色数量失控是「廉价感」的第一来源。
圆角与描边风格不统一，会让画面像从三个不同项目里拼出来的。

### 4. 留白与克制是普世高级感
马远的「一角半边」、倪瓒的疏朗、纽曼的拉链、Agnes Martin 的网格、
北欧极简的空——**东西方独立证明了同一件事**：
「少」传达的自信远大于「多」。

### 5. 东方基因是差异化武器
留白、水墨、线描、气口——这些在西方设计语汇里稀缺，在中文语境里天然熟悉。
跨文化混血（James Jean / 吴冠中路线）最容易做出辨识度。

## 六、可验证性：把审美纪律变成断言

**这是本项目与「一堆风格描述文档」最根本的区别。**

光有纪律不够——纪律必须可判定，否则它只是形容词。
所以每条基因卡的硬纪律都被翻译成**对渲染结果的像素断言**：

| 风格基因 | 纪律（自然语言） | 断言（可判定） |
|---|---|---|
| 中国画留白 | 留白要占大头，朱砂只一点 | `留白 ≥62%` · `彩色像素 ≤6%` · `色相 ≤3` |
| 巴洛克聚光 | 只有一个光源，黑暗要占画面 | `暗部 ≥45%` · `亮部 ≤12%` |
| 极简主义 | 留白是命，点睛色限一个整块 | `留白 ≥46%` · `色相 ≤2` |
| 哥特暗黑 | 铅与烬的物质感，禁正黑 | `暗部 ≥58%` · `色相 ≤3` |

实现见 [`demos/_src/qa_style.py`](../demos/_src/qa_style.py)：
它直接从截图**反推**亮度、暗部占比、留白占比、显著色相数、彩色像素占比，
再逐条比对上表阈值。

同时 [`demos/_src/qa_layout.py`](../demos/_src/qa_layout.py) 挡住另一类事故：
溢出、越界、元素遮挡、字号过小，以及 **WCAG 对比度不足**
（按实际背景色计算，正文 4.5:1、大字 3:1）。

**结果**：12 张作品、34 条风格断言、13 页布局检查——全部可复现、可回归。

> 为什么这很重要：一旦纪律可判定，「有品味」就不再是主观评价，
> 而变成**能通过回归测试的工程属性**。CI 里跑一遍就知道有没有退化。

## 七、这套方法的边界（诚实说明）

| 它**能**做 | 它**不能**做 |
|---|---|
| 让产出摆脱「AI 味默认审美」 | 替代设计师的原创能力 |
| 把风格决策变成可复现、可审查的流程 | 保证产出在审美上「高级」（高级是人的判断） |
| 提供 250+ 艺术家的风格激活词与可执行参数 | 帮你复刻在世创作者的个人风格（见 [`TRADEMARKS.md`](TRADEMARKS.md)） |
| 让风格纪律可回归测试 | 覆盖所有视觉媒介（当前代码基因卡以网页/长图为主） |
| 让品味在团队里可传递、可积累 | 免除你对生成内容合规性的责任 |

**关于在世艺术家**：本仓库收录的是**事实性风格描述与通用关键词**。
它提供的是审美决策方法，**不是「复刻在世创作者」的工具**。
把「用 XX 画师名字生成」当产品卖点，涉及人格权与不正当竞争争议——
这条线请守住。

## 八、怎么参与这套方法的演进

方法论不是固定的。最有效的贡献方式是**回填实战结果**：

```markdown
- YYYY-MM-DD 作品：<主基因> × <辅基因>，关键参数 → 效果 ✅ / ⚠️ / ❌
```

真实的**翻车记录比成功记录更有价值**——它告诉我们哪条纪律需要加固。

详见 [`../CONTRIBUTING.md`](../CONTRIBUTING.md)。
