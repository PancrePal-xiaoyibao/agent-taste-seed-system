## 一、在世创作者（P0 关注项）

`references/chapters/ch23-当代二次元插画师.md` 收录了多位**当代在世插画师**的风格描述。

**本仓库的立场与做法**：

1. **只写事实性风格描述**：写的是「以透明感、柔和的光影和梦幻的配色著称」这类
   **可被公开讨论的视觉特征**，不是对其作品的复制或演绎。
2. **零作品图**：本仓库**不含任何**在世创作者的作品图像、截图或衍生图形（见下方自检）。
3. **零原文引用**：不含任何对其访谈、社媒帖文、画集文字的引用或转述。
4. **署名归位**：描述中出现的姓名，用于**指向该创作者本人**，而非暗示任何合作。

**⚠️ 对外使用时的红线（使用者须知）**：

- ❌ **不得**把「用 XX 画师名字生成」作为产品卖点或宣传话术。
  在世艺术家的姓名 + 商业 AI 生成，涉及**人格权 / 名誉权 / 不正当竞争**争议，
  日本插画师社群对此尤为敏感。
- ❌ **不得**把本仓库的关键词直接当作「模仿某在世创作者」的指令去批量生产商业内容。
- ✅ 正确用法：把关键词当**风格特征的描述**（透明感、柔光、粉彩），
  用于描述你要的**视觉气质**，而不是「我要 XX 的风格」。

> 生成式 AI 与艺术家权益的关系仍在法律与伦理的演进中。
> 本仓库提供的是**审美决策方法**，不是「复刻在世创作者」的工具。
> 使用者须自行承担其生成内容的合规责任。

## 自检：确认本仓库无第三方资产

以下命令应返回**空**（除本仓库自己生成的 `demos/_assets/` 外）：

```bash
# 1) 无图片 / 音视频 / 二进制资产（demos/_assets 是本项目自产的演示截图与字体子集）
git ls-files | grep -iE '\.(jpg|jpeg|png|gif|webp|bmp|tiff|pdf|mp3|mp4|wav|mov|psd|ai|eps)$' \
  | grep -v '^demos/_assets/'

grep -rnE '百度百科|维基百科|wikipedia\.org|知乎|豆瓣|简书|转载自|原文链接' --include='*.md' .

grep -rnoE 'https?://[^"'"'"' )]+\.(png|jpg|jpeg|gif|webp|svg)' --include='*.html' --include='*.md' .
```
